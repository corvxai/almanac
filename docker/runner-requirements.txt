# intentionally minimal; expand only when there is a concrete agent need.
#
# IMPORTANT: do NOT add `bittensor`, `substrate-interface`, `web3`, or any
# chain library here. The runner image is the agent's untrusted side; the
# validator's hotkey + signing logic lives only in the validator container.
#
# IMPORTANT: do NOT add model-provider SDKs (`anthropic`, `openai`,
# `google-generativeai`, `cohere`, etc.). All inference goes through

# DNS, so calling those SDKs directly would fail anyway; not shipping them
# removes attack surface (subdeps, code-reuse gadgets) and forces every
# inference call through the audited path.
